# ImtPlayer

ImtPlayer is a ESP32 based music player that can handle a lot of operations and features a lot of optimizations. 
ImtPlayer will feature-
- **Memory Card Slot** - You can connect your memory to ImtPlayer and it'll play songs!
- **Own Speaker** - Dont have any headphones? No Problem! I have my own speaker!
- **Connectivity with other devices** - You can connect with any device and it'll play songs!
Other features incoming soon!
